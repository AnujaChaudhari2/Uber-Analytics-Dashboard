# Uber Analytics Dashboard

An interactive Power BI dashboard designed to analyze Uber ride performance, bookings, revenue, vehicle types, locations, and customer and driver ratings.

## Project Overview

The dashboard provides an interactive view of Uber's ride and revenue data, helping analyze key business metrics and identify trends across bookings, revenue, vehicle types, locations, and ratings.

## Key Metrics

- Completed Bookings: **93K**
- Lost Bookings: **57K**
- Revenue: **52M**
- Total Distance: **2.51M**
- Average Distance: **24.64**

## Dashboard – Page 1

The first page focuses on an overall business overview, including:

- Monthly booking trends
- Monthly revenue trends
- Revenue by vehicle type
- Completed, cancelled, and incomplete rides
- Top pickup location
- Top drop location
- Average customer rating
- Average driver rating
